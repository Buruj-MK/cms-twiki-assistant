About CMS docs assistant

This tool provides AI-powered semantic search over 44,677 CMS TWiki documentation pages.

It uses a hybrid retrieval pipeline (dense + BM25 → RRF fusion → reranking) with Qwen 2.5-14B for response generation.

Pipeline: TWiki → twiki2gfm.py → chunker.py → UAE-Large-V1 embeddings → ChromaDB → Hybrid retrieval → vLLM

Built by: CMS Documentation Modernisation Team, CERN · Summer 2026
